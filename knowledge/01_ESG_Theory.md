# ESG投资核心理论

## 核心概念

### 什么是ESG？
ESG是环境（Environmental）、社会（Social）和治理（Governance）的缩写，是一种关注企业非财务绩效的投资理念和评价标准。

### ESG投资框架
1. **负面筛选**：排除高污染、高争议行业
2. **正面筛选**：优选ESG表现优异的企业
3. **ESG整合**：将ESG因素纳入传统财务分析
4. **影响力投资**：主动创造社会和环境价值
5. **主题投资**：聚焦清洁能源、可持续农业等

### ESG评级体系
| 评级机构 | 特点 | 覆盖范围 |
|---------|------|---------|
| MSCI | 全球领先，数据全面 | 全球8500+公司 |
| Sustainalytics | 风险导向，独立性强 | 全球20000+公司 |
| CDP | 专注环境，碳披露权威 | 全球10000+公司 |
| 中证/华证 | 本土特色，A股覆盖 | 中国4000+公司 |

## 关键公式

### ESG调整后的资本成本
```
K_ESG = K + λ × ESG_Risk_Premium

其中：
K = 传统资本成本
λ = ESG风险系数
ESG_Risk_Premium = ESG风险溢价
```

### 绿色债券定价
```
P_green = Σ(CF_t / (1 + r_green)^t)

其中：
r_green = r_benchmark - Greenium（绿色溢价）
```

### 常见误区
1. **ESG=慈善**：ESG是风险管理，不是慈善捐赠
2. **ESG=低收益**：研究表明ESG与收益正相关
3. **ESG数据可靠**：不同评级机构差异大，需交叉验证
4. **ESG一劳永逸**：ESG是动态过程，需持续跟踪
