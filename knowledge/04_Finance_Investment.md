# 金融投融资

## 投融资体系

### 1. IPO上市
**核心流程**：
1. 前期准备（财务规范、公司治理）
2. 辅导备案（券商辅导、证监局验收）
3. 申报审核（交易所审核、证监会注册）
4. 发行上市（路演、定价、配售）

**关键要点**：
- 科创板：强调硬科技，允许亏损上市
- 创业板：服务成长型创新创业企业
- 北交所：服务创新型中小企业
- 主板：大盘蓝筹，盈利要求高

### 2. 股权融资
**融资方式**：
| 方式 | 阶段 | 特点 |
|------|------|------|
| 天使投资 | 种子期 | 个人投资，金额小 |
| VC风险投资 | 早期/成长期 | 专业机构，高风险高回报 |
| PE私募股权 | 成熟期 | 大额投资，控股或参股 |
| 战略投资 | 各阶段 | 产业协同，资源整合 |

**融资准备**：
- 商业计划书（BP）
- 财务模型与预测
- 尽职调查材料
- 估值与定价

### 3. 债权融资
**主要工具**：
- 银行贷款（流动资金、固定资产）
- 公司债券（交易所、银行间市场）
- 中期票据（MTN）
- 短期融资券（CP）
- 资产证券化（ABS）

**绿色债券**：
- 募集资金用于绿色项目
- 需要第三方认证
- 信息披露要求更高
- 可能享受绿色溢价（Greenium）

### 4. 并购重组
**并购类型**：
- 横向并购（同行业）
- 纵向并购（产业链）
- 混合并购（多元化）

**并购流程**：
1. 战略规划与目标筛选
2. 尽职调查（财务、法律、业务）
3. 估值与交易结构设计
4. 谈判与签约
5. 监管审批与交割
6. 整合与协同

## 财务分析

### 核心报表
1. **资产负债表**：资产 = 负债 + 所有者权益
2. **利润表**：收入 - 成本 - 费用 = 利润
3. **现金流量表**：经营 + 投资 + 筹资

### 关键指标
| 指标 | 公式 | 意义 |
|------|------|------|
| ROE | 净利润/净资产 | 股东回报率 |
| ROA | 净利润/总资产 | 资产回报率 |
| 毛利率 | (收入-成本)/收入 | 盈利能力 |
| 净利率 | 净利润/收入 | 最终盈利水平 |
| 资产负债率 | 负债/资产 | 财务风险 |
| 流动比率 | 流动资产/流动负债 | 短期偿债能力 |

## 估值方法

### 绝对估值法
**DCF现金流折现**：
```
企业价值 = Σ(FCF_t / (1+WACC)^t) + 终值/(1+WACC)^n

其中：
FCF = 自由现金流
WACC = 加权平均资本成本
```

### 相对估值法
| 方法 | 适用 | 公式 |
|------|------|------|
| P/E市盈率 | 盈利稳定企业 | 股价/每股收益 |
| P/B市净率 | 重资产企业 | 股价/每股净资产 |
| P/S市销率 | 亏损企业 | 市值/销售收入 |
| EV/EBITDA | 资本密集企业 | 企业价值/息税折旧前利润 |
