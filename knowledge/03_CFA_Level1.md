## 习题与答案

### 公司金融
**文档**：高顿CFA一级公司金融【习题】+【答案】
**重点内容**：
- 资本预算决策方法（NPV、IRR、Payback）
- 资本成本计算（WACC）
- 杠杆与资本结构
- 股利政策与股票回购

**核心公式**：
```
WACC = (E/V) × Re + (D/V) × Rd × (1 - Tc)

其中：
E = 股权市值
D = 债务市值
V = E + D（企业总价值）
Re = 股权成本
Rd = 债务成本
Tc = 企业所得税率
```

### 权益投资
**文档**：高顿CFA一级权益投资【习题】+【答案】
**重点内容**：
- 证券市场结构与指数
- 有效市场假说
- 权益估值模型（DDM、FCF、乘数法）
- 行业分析与公司分析

**核心公式**：
```
戈登增长模型：
P0 = D1 / (r - g)

其中：
D1 = 下期预期股利
r = 要求回报率
g = 永续增长率
```

### 固定收益
**文档**：高顿CFA一级固定收益【习题】+【答案】
**重点内容**：
- 债券定价与收益率计算
- 利率风险（久期、凸性）
- 信用风险分析
- 结构化产品（MBS、ABS）

**核心公式**：
```
麦考利久期：
MacD = Σ(t × PV(CFt)) / Σ(PV(CFt))

修正久期：
ModD = MacD / (1 + y)

其中：
y = 每期收益率
```

### 经济学
**文档**：高顿CFA一级经济学【习题】+【答案】
**重点内容**：
- 微观经济学（供需、市场结构）
- 宏观经济学（GDP、通胀、失业）
- 货币政策与财政政策
- 国际贸易与汇率

## 学习建议

### 时间规划
| 阶段 | 时长 | 任务 |
|------|------|------|
| 基础阶段 | 2个月 | 看视频、读教材 |
| 强化阶段 | 1个月 | 做习题、整理笔记 |
| 冲刺阶段 | 2周 | 模考、查漏补缺 |

### 做题策略
1. **理解优先**：不要死记公式，理解原理
2. **错题本**：记录错题，定期复习
3. **限时训练**：模拟考试环境（每题1.5分钟）
4. **知识串联**：建立科目间联系
